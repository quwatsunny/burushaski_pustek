Girmin Editor - User Guide

Welcome to Girmin, your professional book and dictionary editor. This guide will help you get started and make the most of all features.

1. Getting Started

  1. Launch the App: Open Girmin. You will see the Welcome screen with options:
    • Continue where you left off – Resume your last book.
    • New Book – Start a new book project.
    • Load Book – Open an existing book file (.json).
    • Add a dictionary – Add or update spelling dictionaries.
  2. Recent Books: Quickly access your recent projects from the Welcome screen.

2. Creating a New Book

  1. Click New Book on the Welcome screen.
  2. Fill in the book metadata (title, author, summary).
  3. Click Save to start editing your new book.

3. Opening an Existing Book

  1. Click Load Book and select a .json file exported from Girmin.
  2. Your book will open in the editor, ready for editing.

4. Editor Overview

  • Chapters & Paragraphs: Organize your book into chapters and paragraphs. Use the sidebar to add, rename, or reorder them.
  • Rich Text Editing: Use the formatting toolbar for headings, lists, quotes, and more. Paste content—only allowed formatting is kept.
  • References & Footnotes: Add references and footnotes for academic or professional works.
  • Dictionary Integration: Autocomplete and spellcheck are available based on your selected dictionary.
  • Auto-save: Your work is saved automatically in your browser or app.

5. Saving Your Work

  • Save: Click Save to save your book. If you loaded a book from a file, Girmin will save to the same location (in the app) or download a file (in browser).
  • New Save Location: If you started a new book, you will be prompted to choose where to save.
  • Tip: Always keep backups of your exported files.

6. Exporting

  • Export Word: Export your book as a .docx file for Microsoft Word.
  • Export PDF: Export your book as a PDF for printing or sharing.
  • Use the Export buttons in the editor's File menu.

7. Printing

  • Click View Book and use the Print button for a print-optimized version.

8. Dictionaries

  • Click Add a dictionary on the Welcome screen or in Settings.
  • Follow the prompts to upload or update dictionary files.

9. Tips & Troubleshooting

  • If you see a save error, make sure you have permission to write to the selected folder.
  • For seamless saving, always open books using the app's Load Book button.
  • If you lose your work, check the Continue where you left off option on the Welcome screen.
  • Need help? Contact support or check for updates for new features and bug fixes.

10. Keyboard Shortcuts

  • Ctrl+S – Save
  • Ctrl+B – Bold
  • Ctrl+I – Italic
  • Ctrl+U – Underline
  • Ctrl+Z – Undo
  • Ctrl+Y – Redo

11. FAQ

  • Q: Can I use Girmin offline?
    A: Yes, the desktop app works fully offline.
  • Q: What file formats are supported?
    A: JSON (native), DOCX (export), PDF (export).
  • Q: How do I add a new dictionary?
    A: Use the Add Dictionary option on the Welcome or Settings screen.
  • Q: How do I print my book?
    A: Use the View Book > Print option for a print-optimized layout.
